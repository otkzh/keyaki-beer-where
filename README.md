# けやきビール祭り｜いまここ

2026けやきひろば秋のビール祭りの会場図に待ち合わせ位置を表示する、スマートフォン向けの非公式Webアプリです。

## 機能

- 添付された公式会場図PDFから変換したSVGによる、拡大時も鮮明な表示
- ピンチ・マウスホイールによる1〜4倍ズームとドラッグ移動
- 地図をタップして位置を指定
- ヘッダーの「価格」で店舗価格モードに切り替え、会場図の店舗番号をタップしてビールと飲み比べセットの価格を表示
- 店舗番号の選択欄からも全店舗の情報を表示
- 地図上のマーカーをタップしてドロップと十字を切り替え（初期表示はドロップと「ここにいます」）
- 地図の表示とマーカー位置を中央に戻すリセットボタン
- 選択中のマーカーとメッセージを入れた画像の作成・保存・共有
- メイン画面のフッターに共有用URLとQRコードを表示
- 指定した位置の端末内保存

## 実行

アプリの実行にビルドや外部ライブラリは不要です。リポジトリのルートが公開用ディレクトリです。

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

画面は `index.html`、スタイルは `style.css`、操作や画像生成の処理は `app.js` にあります。

## 店舗・ビールデータ

- `data/beers.json`: 出店番号1〜52の店舗、地域、公式詳細URL、会場図上の位置、飲み比べセット、ビール、サイズ・容量・価格を階層化したデータ
- `data/beers.csv`: セットは1行、ビールは価格・サイズごとに1行にした表。Excelで開きやすいUTF-8（BOM付き）
- 出典: [公式ビール一覧](https://www.beerkeyaki.jp/beer/) と [公式会場図PDF](https://www.beerkeyaki.jp/files/uploads/2026autumn.pdf)

取得時点で52店舗、ビール390件、飲み比べセット68件、CSVは1,232行です。公式ページで価格が空欄のビール4件と価格行2件は空欄のまま収録しています。出店番号52は会場図に番号が描かれていないため、図上の「SORACHI 1984」ブース中央に対応付けました。価格・販売内容は変更される場合があるため、画面内の公式詳細リンクでも確認できます。

データを更新する場合は、次のコマンドを実行します。

```sh
python3 -m pip install beautifulsoup4 pymupdf
python3 scripts/update_beer_data.py
```

## 位置の指定

地図をタップして待ち合わせ位置を指定してください。位置はサーバーへ送信せず、端末のlocalStorageに保存します。
