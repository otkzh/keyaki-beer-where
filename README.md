# けやきビール祭り｜いまここ

2026けやきひろば秋のビール祭りの会場図に待ち合わせ位置を表示する、スマートフォン向けの非公式Webアプリです。

## 機能

- 添付された公式会場図PDFから変換したSVGによる、拡大時も鮮明な表示
- ピンチ・マウスホイールによる1〜4倍ズームとドラッグ移動
- 地図をタップして位置を指定
- ビール祭りに合う10種類のマーカーと10種類のメッセージを、ボタンでランダムに組み合わせ（初期表示はピンと「ここにいます」）
- 地図の表示とマーカー位置を中央に戻すリセットボタン
- 選択中のマーカーとメッセージを入れた画像の作成・保存・共有
- メイン画面のフッターに共有用URLとQRコードを表示
- 指定した位置の端末内保存

## 実行

ビルドや外部ライブラリは不要です。リポジトリのルートが公開用ディレクトリです。

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

画面は `index.html`、スタイルは `style.css`、操作や画像生成の処理は `app.js` にあります。

## 位置の指定

地図をタップして待ち合わせ位置を指定してください。位置はサーバーへ送信せず、端末のlocalStorageに保存します。

## 会場図の出典

- けやきひろばビール祭り公式サイト: https://www.beerkeyaki.jp/map/
- 元PDF: https://www.beerkeyaki.jp/files/uploads/2026autumn.pdf
- SVG: `2026autumn-vector.svg`

会場図の権利は元の権利者に帰属します。本アプリは非公式であり、主催者による提供・承認を示すものではありません。会場図をアプリ独自の著作物や自由利用可能な素材として扱うものではありません。

SVGはPDFの文字の輪郭を保持して変換しており、表示端末への日本語フォントのインストールは不要です。
